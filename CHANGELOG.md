# Changelog

All notable changes to the Yaltaan packages are documented in this file. The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and the packages follow [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html): an API marked `@stable` changes incompatibly only in a major version; an API marked `@experimental` may change in a minor version, and such a change is marked **Breaking**.

No entry predates the first published version; user-visible changes only.

## [Unreleased]

### Added

- `@yaltaan/core/result`: the `Result<T, E>` type, a read-only object discriminated by `ok`, and the free functions `ok`, `err`, `mapResult` and `unwrapOr` (`@experimental`).
- `@yaltaan/core/path`: the `Path` and `PathSegment` types, with the `{ key }` segment; `parsePath` and `formatPath` for the text form, bounded in length and depth; `checkWritablePath`, which refuses `__proto__`, `constructor` and `prototype` before a write; issues `path.syntax`, `path.too_long`, `path.too_deep`, `path.not_textual` and `path.forbidden_segment` (`@experimental`).
- `@yaltaan/core/issue`: the `Issue` type, one shape for every expected failure (stable code, `Path`, parameters, severity, cause), and `IssueFormatter`; `toStandardIssue`, which builds the Standard Schema issue with the application's formatter and resolves `{ key }` segments to indexes; `fromStandardIssue`, which reads the issue of another Standard Schema validator as `issue.external` (`@experimental`).
- `@yaltaan/core/equal`: `equal`, a deep equality over plain objects, arrays, `Map`, `Set`, `Date`, typed arrays and Temporal objects, by SameValueZero or `Object.is`, symbol keys opt-in; cycles end and shared branches are compared once, at any depth; class instances and other objects compare by identity (`@experimental`).
- `@yaltaan/core/object`: `pick`, `omit` and `redact`, which select fields by a mask shaped like the value (`{ password: true, address: { geo: true } }`), nested records and the elements of arrays included; the `Mask<T>` type, checked key by key against the value at every depth, and the result types `Picked`, `Omitted` and `Redacted` (`@experimental`).
- `@yaltaan/core/object`: `merge`, a deep merge with an explicit array strategy (`'replace'` or `'concat'`), `defaults`, which fills missing or `undefined` fields at every depth, and `mapValues` and `mapKeys`; the types `Merged`, `Defaulted`, `ArrayStrategy`, `MergeOptions` and `KeyOptions`, which `MaskOptions` now extends (`@experimental`).
- `@yaltaan/core/equal`: the `pick` and `omit` options (`EqualMasks<T>`), to compare only the fields a mask names, or all but those, checked against the type of the first value (`@experimental`).
- `@yaltaan/core/object`: `get`, `has`, `set`, `update` and `remove` by `Path`, which tell a missing field from an `undefined` one, copy only along the path, never mutate nor create holes, create missing containers on request (`createMissing`), and match `{ key }` segments by a `keyOf` option; issues `path.missing` and `path.not_traversable` (`@experimental`).
- `@yaltaan/core/collection`: `partition`, `indexBy`, which refuses a repeated key with the code `collection.duplicate_key`, `countBy`, `uniqueBy`, `intersectionBy` and `differenceBy`, over any iterable read once, with keys of any type compared by SameValueZero (or `Object.is` with `equality: 'SameValue'`) and held in a `Map` (`@experimental`).
- `@yaltaan/core/collection`: `minBy` and `maxBy`, `topK`, the `k` first elements of `toSorted` kept in a heap of `k` elements, `sortBy` by several keys, each computed once, over the stable native sort, and `paginate`, numbered from 0 under the names of Angular Material's paginator; one order on keys, numbers before strings and `undefined`, `null` and `NaN` last in both directions, and a comparator that is not consistent never loops (`@experimental`).
- `@yaltaan/core/number`: `parseNumber`, a strict reading of number text to a `Result`, with explicit decimal and group separators, bounded in length, that refuses a text the number read cannot hold (issues `number.syntax`, `number.too_long`, `number.out_of_range`, `number.inexact`); `clamp` and `inRange` with named bounds; `approxEqual` with explicit absolute and relative tolerances; `round` by the nine named modes of `Intl.NumberFormat`, on the shortest decimal of the number; `bigIntToNumber` and `numberToBigInt`, exact or an issue (`number.not_integer`) (`@experimental`).
- Registry of the issue codes of `@yaltaan/core`, a guide in English and French for each sub-path, and an English formatter to copy.

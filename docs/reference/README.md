## Contract tags

An export that runs (a function, a constant that can be called, a class) carries the whole contract; an export that never runs (a constant, an interface, a type alias) carries `@since` and its stability only. Any tag missing from this table fails the gate.

| Tag | Value | Carried by | Presence | Meaning |
|---|---|---|---|---|
| `@pure` | none | functions, classes | either `@pure` or `@mutates`, never both | Mutates none of its arguments. |
| `@mutates` | a parameter name | functions, classes | either `@pure` or `@mutates`, never both | Mutates the parameter it names; one tag per mutated parameter. |
| `@sharing` | `none`, `structural`, `identity-preserving` | functions, classes | required, once | What the result shares with the arguments: nothing, unchanged parts (structural), or the argument itself when nothing changes (identity-preserving). |
| `@complexity` | starts with `O(` | functions, classes | required, once | Time complexity, with what `n` counts. |
| `@throws` | `never` alone, or text | functions, classes | required, repeatable | `never`, or one tag per condition under which it throws (a violated precondition: a bug of the caller). |
| `@since` | MAJOR.MINOR | functions, classes, constants, types | required, once | The minor version that added the export. |
| `@experimental` | none | functions, classes, constants, types | either `@experimental` or `@stable`, never both | May change in a minor version. |
| `@stable` | none | functions, classes, constants, types | either `@experimental` or `@stable`, never both | Follows SemVer strictly: changes incompatibly only in a major version. |
| `@param` | a parameter name, then text | functions, classes | optional, repeatable | Describes the parameter it names first. |
| `@returns` | text | functions | optional, once | Describes the result. |
| `@typeParam` | text | functions, classes, constants, types | optional, repeatable | Describes a type parameter. |
| `@example` | text | functions, classes, constants, types | optional, repeatable | An example of use. |
| `@see` | text | functions, classes, constants, types | optional, repeatable | A related export or document. |
| `@deprecated` | text | functions, classes, constants, types | optional, once | What to use instead. |

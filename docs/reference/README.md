## Contract tags

An export that runs (a function, a constant that can be called, a class) carries the whole contract; an export that never runs (a constant, an interface, a type alias) carries `@since` and its stability only. A callable member of an export (a method, a property whose value is a function) carries the contract of a function, unless it is supplied by the caller (`@supplied`); `@since` and the stability of a member are its owner's when it does not state its own ([ADR 0040](../adr/0040-contract-tags-of-members.md)). Any tag missing from this table fails the gate.

| Tag | Value | Carried by | Presence | Meaning |
|---|---|---|---|---|
| `@pure` | none | functions, classes, members | either `@pure` or `@mutates`, never both | Mutates none of its arguments. |
| `@mutates` | a parameter name, or `this` on a member | functions, classes, members | either `@pure` or `@mutates`, never both | Mutates the parameter it names; one tag per mutated parameter. On a member, `this` names the object it is called on (the instance, or the exported object). |
| `@sharing` | `none`, `structural`, `identity-preserving` | functions, classes, members | required, once | What the result shares with the arguments: nothing, unchanged parts (structural), or the argument itself when nothing changes (identity-preserving). |
| `@complexity` | starts with `O(` | functions, classes, members | required, once | Time complexity, with what `n` counts. |
| `@throws` | `never` alone, or text | functions, classes, members | required, repeatable | `never`, or one tag per condition under which it throws (a violated precondition: a bug of the caller). |
| `@since` | MAJOR.MINOR | functions, classes, constants, types, members, supplied members | required, once; on a member, optional | The minor version that added the export, or the member. |
| `@experimental` | none | functions, classes, constants, types, members, supplied members | either `@experimental` or `@stable`, never both; on a member, optional | May change in a minor version. |
| `@stable` | none | functions, classes, constants, types, members, supplied members | either `@experimental` or `@stable`, never both; on a member, optional | Follows SemVer strictly: changes incompatibly only in a major version. |
| `@supplied` | none | supplied members | required, once | Supplied by the caller and called by the library: no promise on its effects or its cost, and its description says when it is called and what it must do. |
| `@param` | a parameter name, then text | functions, classes, members, supplied members | optional, repeatable | Describes the parameter it names first. |
| `@returns` | text | functions, members, supplied members | optional, once | Describes the result. |
| `@typeParam` | text | functions, classes, constants, types, members, supplied members | optional, repeatable | Describes a type parameter. |
| `@example` | text | functions, classes, constants, types, members, supplied members | optional, repeatable | An example of use. |
| `@see` | text | functions, classes, constants, types, members, supplied members | optional, repeatable | A related export or document. |
| `@deprecated` | text | functions, classes, constants, types, members, supplied members | optional, once | What to use instead. |

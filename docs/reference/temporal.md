### `TemporalIssue`

A type.

An expected failure of this package. An issue never holds the text it refused: - `temporal.inverted_interval`: the start of an interval comes after its end; - `temporal.too_large`: more intervals, holidays or days than `maximum`, or a number of days that is not an integer; - `temporal.ambiguous_format`: no format says how to read this text, or `yy` has no `pivotYear`; - `temporal.invalid_format`: the format cannot be read: an unknown letter, a token used twice, a missing field; - `temporal.format_mismatch`: the text does not follow the format from the code unit `at`; - `temporal.too_long`: the text has more than `maximum` code units; - `temporal.invalid_date`: no such date or time, or an invalid `Date`; - `temporal.invalid_time_zone`, `temporal.invalid_calendar`: Temporal does not know this name; - `temporal.nonexistent_time`: this wall clock does not exist in this zone: the clock jumps over it; - `temporal.ambiguous_time`: this wall clock exists twice in this zone: the clock goes back over it; - `temporal.out_of_range`: the result would fall outside the range of Temporal; - `temporal.no_business_day`: every day of the week is in the weekend.

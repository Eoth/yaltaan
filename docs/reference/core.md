### `equal`

A function.

Whether `a` and `b` hold the same data: primitives by SameValueZero (or `Object.is`), records, arrays, `Map`, `Set`, `Date`, typed arrays and Temporal objects by content, anything else by identity. Two structures are equal when walking them in step never finds a difference, so cycles end and an aliased subtree is compared once.

```ts
export declare function equal(a: unknown, b: unknown, options?: EqualOptions): boolean;
```

| Contract | Value |
|---|---|
| `@pure` | yes |
| `@sharing` | none |
| `@complexity` | O(n) (n = values reached), O(n × m) at worst between two cyclic graphs (m = objects of `b`) |
| `@throws` | TypeError when `equality` is neither 'SameValueZero' nor 'SameValue', or `symbols` is not a boolean |
| `@throws` | what a getter, a Proxy trap or the `equals` method of a Temporal object throws, unchanged |
| `@throws` | TypeError when an object borrows the prototype of `Map`, `Set` or `Date` without being one |
| `@since` | 0.1 |
| `@experimental` | yes |

**Example**

```ts
equal({ tags: ['a'], at: new Date(0) }, { tags: ['a'], at: new Date(0) }) // true
```

### `PathIssue`

A type.

Why a path could not be read, written as text, or used for a write. `path` is the path concerned, empty for a text that could not be read; `params` holds the data a message is built from. - `path.syntax`: the text breaks the grammar at code unit `index`, where a bracket or a name that cannot be read starts, or where a code unit stands that no segment can start with. - `path.too_long`: the text is `length` code units long, over `maximum`. - `path.too_deep`: the text holds more than `maximum` segments. - `path.not_textual`: the segment at `index` has no text form (a symbol, a key segment, a number that is no index). - `path.forbidden_segment`: the segment at `index` is `__proto__`, `constructor` or `prototype`.

```ts

    readonly params: {
        readonly length: number;
        readonly maximum: number;
```

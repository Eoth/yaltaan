### `equal`

A function.

Whether `a` and `b` hold the same data: primitives by SameValueZero (or `Object.is`), records, arrays, `Map`, `Set`, `Date`, typed arrays and Temporal objects by content, anything else by identity. Two structures are equal when walking them in step never finds a difference, so cycles end and an aliased subtree is compared once. A `pick` or `omit` mask, checked against the type of `a`, restricts the fields of records compared.

```ts
export declare function equal<T>(a: T, b: unknown, options?: EqualOptions & EqualMasks<NoInfer<T>>): boolean;
```

| Contract | Value |
|---|---|
| `@pure` | yes |
| `@sharing` | none |
| `@complexity` | O(n) (n = values reached), O(n × m) at worst between two cyclic graphs (m = objects of `b`) |
| `@throws` | TypeError when `equality` is neither 'SameValueZero' nor 'SameValue', or `symbols` is not a boolean |
| `@throws` | TypeError when both `pick` and `omit` are given |
| `@throws` | TypeError when a mask or one of the entries read is neither `true` nor a plain object |

export declare function mapKeys<T extends object, K extends PropertyKey>(record: T, rename: (key: KeyName<T>, value: T[keyof T]) => K, options?: KeyOptions): Partial<Record<K, T[keyof T]>>;

| Contract | Value |
|---|---|
| `@pure` | yes |
| `@sharing` | structural |
| `@complexity` | O(n) (n = keys of the record), plus one call of `rename` per key |
| `@throws` | TypeError when `record` is not a plain object, `rename` returns no property key, or `symbols` is no boolean |
| `@throws` | what `rename`, a getter or a Proxy trap throws, unchanged |
| `@since` | 0.1 |
| `@experimental` | yes |

**Example**

```ts

```

### `merge`

A function.

`overrides` laid over `base`: two records are merged field by field, at every depth, the fields of `overrides` winning; two arrays are joined or replaced as `arrays` says; anything else is `overrides`, even `undefined`, as a spread `{ ...base, ...overrides }` does one level deep. Neither value is changed; what is not merged is shared.

```ts
export declare function merge<A, B, S extends ArrayStrategy>(base: A, overrides: B, options: MergeOptions<S>): Merged<A, B, S>;
```

| Contract | Value |

### `PathIssue`

A type.

Why a path could not be read, written as text, or used for a write. `path` is the path concerned, empty for a text that could not be read; `params` holds the data a message is built from. - `path.syntax`: the text breaks the grammar at code unit `index`, where a bracket or a name that cannot be read starts, or where a code unit stands that no segment can start with. - `path.too_long`: the text is `length` code units long, over `maximum`. - `path.too_deep`: the text holds more than `maximum` segments. - `path.not_textual`: the segment at `index` has no text form (a symbol, a key segment, a number that is no index). - `path.forbidden_segment`: the segment at `index` is `__proto__`, `constructor` or `prototype`.

```ts
export type PathIssue = {
    readonly code: 'path.syntax';
    readonly path: Path;
    readonly params: {
        readonly index: number;
    };
} | {
    readonly code: 'path.too_long';
    readonly path: Path;
    readonly params: {
        readonly length: number;
        readonly maximum: number;
    };
} | {
    readonly code: 'path.too_deep';
    readonly path: Path;
    readonly params: {
        readonly maximum: number;
    };
} | {
    readonly code: 'path.not_textual';
    readonly path: Path;
    readonly params: {
        readonly index: number;
    };
} | {
    readonly code: 'path.forbidden_segment';
    readonly path: Path;
    readonly params: {
        readonly index: number;
        readonly segment: string;
    };
};
```

| Contract | Value |
|---|---|
| `@since` | 0.1 |
| `@experimental` | yes |

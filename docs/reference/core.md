### `PathIssue`

A type.

Why a path could not be read, written as text, or used for a write. `path` is the path concerned, empty for a text that could not be read; `params` holds the data a message is built from. - `path.syntax`: the text breaks the grammar at code unit `index`, where a bracket or a name that cannot be read starts, or where a code unit stands that no segment can start with. - `path.too_long`: the text is `length` code units long, over `maximum`. - `path.too_deep`: the text holds more than `maximum` segments. - `path.not_textual`: the segment at `index` has no text form (a symbol, a key segment, a number that is no index). - `path.forbidden_segment`: the segment at `index` is `__proto__`, `constructor` or `prototype`.

```ts
export type PathIssue = {
    readonly code: 'path.syntax';
    readonly path: Path;
    readonly params: {
        readonly index: number;
    };
} | {
    readonly code: 'path.too_long';
    readonly path: Path;
    readonly params: {
        readonly length: number;
        readonly maximum: number;
    };
} | {
    readonly code: 'path.too_deep';
    readonly path: Path;
    readonly params: {
        readonly maximum: number;
    };
} | {
    readonly code: 'path.not_textual';
    readonly path: Path;
    readonly params: {
        readonly index: number;
    };
} | {
    readonly code: 'path.forbidden_segment';
    readonly path: Path;
    readonly params: {
        readonly index: number;
        readonly segment: string;
    };
};
```

### `formatPath`

A function.

Writes the text form of a path, which `parsePath` reads back to the same segments: a string segment as a name where it is an ASCII identifier and as a quoted key elsewhere, an index in brackets. A symbol, a key segment or a number that is no index (negative, fractional, unsafe, NaN) has no text form; `-0` is written as the index 0.

```ts
export declare function formatPath(path: Path): Result<string, PathIssue>;
```

| Contract | Value |
|---|---|

| `@throws` | never |
| `@since` | 0.1 |

**Example**

### `parsePath`

A function.

Reads the text form of a path (`items[3].name`, `["a.b"][0]`), by the grammar written in this module. The text is untrusted: its length and its number of segments are bounded, and any departure from the grammar is an issue that names where it is, never a guess.

```ts
export declare function parsePath(text: string, options?: ParsePathOptions): Result<Path, PathIssue>;
```

| Contract | Value |
|---|---|
| `@pure` | yes |
| `@sharing` | none |
| `@complexity` | O(n) (n = length of the text) |
| `@throws` | TypeError when `text` is not a string |
| `@throws` | RangeError when `maxLength` or `maxDepth` is neither a non-negative integer nor Infinity |
| `@since` | 0.1 |
| `@experimental` | yes |

**Example**

```ts
parsePath('items[3].name') // { ok: true, value: ['items', 3, 'name'] }
```
